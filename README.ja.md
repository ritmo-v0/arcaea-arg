# Arcaea ARG

Arcaea の歴代 ARG に関する資料をまとめたものです。バージョンごとに整理し、それぞれの詳しい記録を添えています。

## Version 7.0

ストーリーパック **Divine Oblivion** へと繋がった ARG。その一部は `quietandlightless.world` 上で展開されており、[v7.0](v7.0) に収めてあるのはその内容です。

全記録（繁体字中国語）：

- [Part I](https://ritmo.dev/articles/SymKwPfwzl)
- [Part II](https://ritmo.dev/articles/S1GvS7guMx)

コードは読みやすさのために整理してあります：

- 文字列配列の難読化解除（String Array Deobfuscation）
- Astro 本体と、パズルと無関係な外部ライブラリ（GA4、Motion など）は除外
- 構造がほぼ同じページは一つのファイルに統合し、どこが元のどれに当たるかはコメントで明示
- 一部の箇所は説明用のコメントに差し替え
