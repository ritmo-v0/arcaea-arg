# Arcaea ARG

Arcaea 歷代 ARG 的相關資料整理，依版本區分，並附上各自的完整紀錄。

## Version 7.0

通往故事曲包 **Divine Oblivion** 的 ARG。其中一部分在 `quietandlightless.world` 上進行，也就是 [v7.0](v7.0) 收錄的內容。

完整紀錄（繁體中文）：

- [Part I](https://ritmo.dev/articles/SymKwPfwzl)
- [Part II](https://ritmo.dev/articles/S1GvS7guMx)

程式碼為了便於閱讀而整理過：

- 字串陣列反混淆（String Array Deobfuscation）
- 拿掉 Astro 本身，以及與謎題無關的第三方套件（GA4、Motion 等）
- 結構高度相似的頁面合併為同一份檔案，並以註解標示各自的出處
- 少部分片段改寫為說明用的註解
